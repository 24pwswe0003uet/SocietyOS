## Read this first

- The default Worker deploys **React static assets** and optionally proxies `/api/*`.
- It **does not host FastAPI or PostgreSQL**. Your API requires a separately reachable backend.
- Optional Python Worker adapter templates are in the kit for a future source-specific port.
- The scanner flags patterns requiring review, not definitive incompatibilities.

## Deploy checklist

- [ ] `node cloudflare/build.mjs` finishes with `frontend/dist/index.html`.
- [ ] All frontend API calls use relative `/api/...` URLs, or are correctly configured for the deployed API.
- [ ] If API functionality is needed, set `API_BACKEND_URL` in Cloudflare Worker settings to a public HTTPS backend.
- [ ] Never set `API_BACKEND_URL` to localhost, 127.0.0.1 or a private address.
- [ ] Do not commit `.env`, private keys, or real production secrets.
- [ ] Verify login, registration, and `/api/v1/auth/me` in the deployed application.

## Direct Python backend deployment

Cloudflare Python Workers require Python-Workers-compatible dependencies, an ASGI Worker entrypoint,
appropriate database connections, and reviewed startup behavior. This project has NOT been ported to
Cloudflare Python Workers by the default kit. A generic adapter cannot establish compatibility.
